# ☕ Java Programming and Database Connectivity

A comprehensive repository demonstrating my learning and hands-on projects in **Core Java** and **JDBC (Java Database Connectivity)**.  
This repository showcases my understanding of **object-oriented programming**, **database interaction**, and **real-world problem-solving using Java**.

---

## 🎯 Objective

To build a strong foundation in **Java programming** and master **database connectivity (JDBC)** for creating interactive, data-driven applications.

---

## 🧠 Key Concepts Covered

### 🔹 Core Java
- Fundamentals of Java (Data Types, Variables, Operators)
- Control Statements (if, switch, loops)
- Object-Oriented Programming (OOPs)
  - Classes & Objects  
  - Inheritance  
  - Polymorphism  
  - Abstraction  
  - Encapsulation
- Exception Handling
- Collections Framework (ArrayList, HashMap, LinkedList, etc.)
- File Handling
- Multithreading Basics

### 🔹 JDBC (Java Database Connectivity)
- JDBC Architecture and Drivers
- Establishing Database Connection
- Executing SQL Queries using `Statement` and `PreparedStatement`
- Handling ResultSet for Data Retrieval
- Transaction Management
- CRUD Operations (Create, Read, Update, Delete)
- Connecting Java with MySQL / SQL Server
